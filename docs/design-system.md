# Design System - Smart HRM (Frontend ReactJS)

## Phong cách
Modern Enterprise & Clean Dashboard (tham khảo SAP, Jira, Workday), ưu tiên mật độ dữ liệu cao.

## Bố cục
- Layout 2 cột: Sidebar cố định bên trái (Nhân sự, Chấm công, Lương, KPI, AI Chatbot), nội dung chính bên phải.
- Grid rõ ràng; Metrics Cards ở đầu trang; Data Tables cho bảng biểu.

## Màu sắc
- Primary: Navy / Royal Blue.
- Background: `#F4F6F9` (light). Dark mode riêng cho khung AI Chat.
- Trạng thái: xanh lá (hoạt động/thành công), cam/vàng (chờ duyệt/cảnh báo), đỏ (từ chối/vi phạm).

## Kiểu chữ
Sans-serif: Inter, Roboto hoặc Segoe UI. Số liệu lớn phải dễ quét.

## Hiển thị dữ liệu & tương tác
- Data Tables: tìm kiếm nhanh, phân trang, lọc theo phòng ban, sticky header.
- Biểu đồ (Recharts): quỹ lương, biến động nhân sự, hiệu suất KPI.
- AI: Floating Chat Widget hoặc Chat Drawer ở góc màn hình.
